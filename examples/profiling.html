Trace analysis

Open an engine trace with the timeline and analysis tables ready to use.

  • Slow nodes: find expensive nodes within each model and execution context.
  • Run summary / Runs: compare the first recorded call, later calls, median, p95 and individual timings.
  • Copies and waits: inspect transfers, submissions, blocking waits and asynchronous completion.
  • Memory: compare observed allocator peaks, growth, allocations and frees.

Host operators and GPU operators also show totals by operator type. All tables cover the whole capture. Host calls are not end-to-end request latency; host and GPU times stay separate.

Check the Capture tab for missing events and GPU timing coverage. Memory shows partial allocator inventories, not physical RAM or VRAM. An empty table means no usable observations.
